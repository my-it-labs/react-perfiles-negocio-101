# Conceptos, con esquemas

[← Página anterior](../README.md) · [Siguiente página →](C01-ecosistema/README.md)

Este recorrido explica el ecosistema React sin pedir que programes. Cada página lleva un esquema. El hilo conductor es un **panel de servicio**: una búsqueda, un filtro y una lista de líneas. Es el mismo gesto que describe la documentación de React en [Pensar en React](https://es.react.dev/learn/thinking-in-react): partir de un boceto, rodear las piezas y seguir el dato.

El otro recorrido abre las demos del repositorio y mira el código. Este se queda en el dibujo y en las preguntas que puedes hacer delante de una propuesta.

![Cinco pasos: rodear el boceto, nombrar el árbol, dejar la pantalla quieta, quedarse con el mínimo que cambia y subir el clic.](img/cinco-pasos.svg)
