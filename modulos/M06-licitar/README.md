# M06 — Licitar una aplicación

[← Página anterior](../../demos/next/guia/flujo/06-lectura.md) · [Siguiente página →](01-el-pliego/01-que-se-encarga.md)

Los módulos anteriores enseñan a leer una frase de propuesta y una entrega. Este escribe el documento al que el proveedor tiene que contestar: el pliego de prescripciones técnicas. Dice qué uso se compra, en qué superficie, de dónde sale el dato y cómo se comprueba. Las cláusulas del procedimiento —solvencia, garantías, precio, penalizaciones— las cierra quien lleva la contratación. Aquí no se improvisan.
